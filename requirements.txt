# 版本策略：下面 `==` 的版本是本机（Windows 11 / Python 3.13.7）实测跑通的组合。
# 想放宽限制的话，把 `==` 换成 `>=` 即可，但注意两处已知的版本敏感点：
#   1) chromadb —— 1.x 的自定义 embedding function 必须实现 embed_query()，
#      只有 __call__ 的话每次 query 都会静默降级成关键词搜索（见 rag_builder.py 注释）
#   2) streamlit —— app.py 里有一段针对 1.64 DOM 结构的 CSS，换大版本可能要跟着改
#
# 装完可以跑 `python -c "import fastapi, chromadb, streamlit"` 自检。
