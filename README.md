# 智能学习平台

一个跑在自己电脑上的 AI 学习助手。把课程资料（PDF / Word / PPT）丢进去，它就能**照着你的资料**答疑、出题、判分，并记录掌握情况。

- 原件、索引和学习记录保存在本机。问答和出题会向已配置的大模型服务发送问题或主题，以及本轮用到的资料片段
- 不需要 GPU，也不需要联网就能建知识库（内置离线嵌入）
- 前后端分离：Streamlit 界面 + FastAPI 服务

## 界面一览

| 标签页 | 作用 |
|---|---|
| 🧭 对话学习 | 支持限定单份课件提问，回答引用可查看原文和原页 |
| 🎯 测验 | 按主题或课程知识点出题，提交后查看逐项评分和失分原因 |
| 📈 掌握曲线 | **按知识点**统计正确率折线图，并挑出「需要加强的知识点」 |
| ❌ 错题本 | 查看原答、评分和出处，直接生成同知识点的变式题 |
| 🗓️ 复习路径 | 设置课程目标、关联课件和知识点，查看下一项复习任务 |
| 🧠 思维导图 | 把答题记录里出现过的知识点画成关系图，也能手动添加节点 |
| 📚 资料库 | 上传资料、在线翻阅、下载、删除 |

## 环境要求

- **Windows**（`.doc/.ppt` 转 PDF 走 Office COM；`/solve` 沙箱依赖 `subprocess`）
- **Python 3.10 及以上**（实测 3.13.7）
- **可选：Microsoft Office** —— 只有需要把 Word / PPT 转成 PDF 在线预览时才用得上。没装也能用，只是那类资料不能在线翻页，正文照常入库

## 安装

```bash
git clone https://github.com/24050423/lite-tutor.git
cd lite-tutor

pip install -r requirements.txt

# 填自己的大模型密钥 —— 仓库里故意不放密钥
copy local_secrets.example.py local_secrets.py
```

然后打开 `local_secrets.py`，把 `DEEPSEEK_API_KEY` 换成自己的（[DeepSeek 开放平台](https://platform.deepseek.com/)申请）。
这个文件在 `.gitignore` 里，不会被提交；不填也能启动，只是对话和判分会返回鉴权失败。

## 启动

双击 `start_tutor.bat`，它会开两个终端窗口：

- **后端** `server.py` → http://127.0.0.1:8000 （接口文档在 `/docs`）
- **前端** `app.py` → http://localhost:8501 （浏览器会自动打开）

关闭系统：直接关掉那两个终端窗口，或在窗口里按 `Ctrl+C`。

> 后端要先起好，前端才连得上。`start_tutor.bat` 里已经加了 3 秒等待；
> 如果前端打开后一片空白或提示连接失败，多半是后端还在加载 —— ChromaDB 首次启动要十几秒。

## 配置

全部通过环境变量，不改代码：

| 变量 | 默认值 | 说明 |
|---|---|---|
| `DEEPSEEK_API_KEY` | 取自 `local_secrets.py` | 大模型密钥。环境变量优先于文件；界面上**不需要**手填 |
| `DEEPSEEK_BASE_URL` | `https://api.deepseek.com/v1` | 接口地址，换成兼容 OpenAI 协议的任意服务都行 |
| `TUTOR_OFFLINE` | `auto` | 新库的嵌入选择。`auto` 检查可用性，`1` 使用内置哈希，`0` 尝试句向量。旧库沿用已有嵌入。离线设置禁止加载旧库的句向量，转为关键词检索 |
| `RAG_CONF_THRESHOLD` | `0.35` | 问答和测验的检索门槛。每个片段达到向量相似度或关键词覆盖率门槛即可参与排序 |
| `EDGE_PUBLIC_URL` | `http://127.0.0.1:8000` | 后端对外暴露的地址，多机部署时才需要改 |

界面上能调的东西（接口地址、模型、温度、外观、打字机速度、知识库开关）在左侧 **⚙️ 设置** 里，自动存进 `ui_settings.json`，刷新不丢。

## 使用说明

### 🧭 对话学习

开启知识库后（默认开），可以选择「全部资料」或单份资料再提问。回答中标有 `【出处1】` 等编号时，可以在下方展开对应的文件名、页码和片段。点击「打开原页」会打开该页的 PDF。引用会随会话保存。

课件不足时，模型会收到将通用知识单独呈现的提示。只有能对应本轮候选资料的编号才会显示为出处。界面也会提示无命中、超时和关键词降级。

知识库开关在 **⚙️ 设置 → 🔌 连接 → 📚 回答前先查知识库**。关掉就退化成纯通用问答，好处是每轮少一次检索、少带约 1000 字上下文，回答更快。

### 🎯 测验

输入考察主题（如「递归」「SQL 查询」），在「出题范围」选择全部资料或单份资料。题目下方可查看出题时提供的片段。指定范围没有相关内容时，会提示这是通用题。

有课件片段时，测验页面优先调用 DeepTutor 阅读测验生成选择题，校验答案依据是否确实来自该片段。选择题按保存的标准选项批改。通用题和旧题继续用简答题。简答题使用 DeepTutor 语义评分逐项返回「达到」「部分达到」「未达到」，分别记 1、0.5 和 0 分，75 分通过。模型可用但判断依据不足时请补充回答，模型请求失败时仍可降级到关键词评分。每道题只计首次有效提交。

### 📈 掌握曲线 / ❌ 错题本 / 🧠 思维导图

三个页面读取同一份答题记录。页面上方可查看当前会话或指定课程。课程统计涵盖该课程在不同会话中的练习。

- **掌握曲线**显示各知识点的练习通过率。无法可靠归入课程的旧记录可以在「待归类的旧练习」展开查看。
- **错题本**列出未通过的练习，显示原答、失分原因和出处。点击「同知识点重练」进入测验，系统会生成一道新题。
- **思维导图**以当前课程或会话为中心，显示练习过的知识点，可手动添加临时节点。

### 🗓️ 复习路径

在「课程设置」创建课程，填写学习目标，选择课件，并按行添加知识点。课程可关联多份课件。同名知识点在不同课程中分别统计。未关联课件时使用通用题。

复习路径用 DeepTutor 的间隔复习算法回放课程答题记录。首次通过通常在 3 天后复习，连续通过会拉长间隔，未通过则安排约 10 分钟后的短间隔复习。「明天再练」和「标记完成」会保存安排，答题次数只由提交答案更新。

### ⚙️ 设置

- **连接**：接口地址、模型、Temperature / Max Tokens、System Prompt、算力自适应模式、知识库开关
- **外观**：字体大小、浅色 / 深色主题、主题色（联动图表与选中态）、字体、页面宽度
- **便利**：打字机效果速度

「算力自适应模式」决定对话时给不给模型挂工具：

| 模式 | 说明 |
|---|---|
| Lite | 纯文本云端推理，不挂工具 |
| Standard | 默认。多模态交互、语义评分 |
| Pro | 挂上工具链，模型可以主动调用沙箱算数学 / 跑代码、查知识库、出题、判分 |

### 🕘 历史会话

所有会话按最近活动时间**铺开列在侧边栏**，点哪条切哪条，当前那条高亮置灰。会话 ID 写进地址栏，刷新页面能回到同一个会话。

- **新增**：「➕ 新建会话」
- **导出**：「📤 导出」把当前对话存成 Markdown
- **删除**：先点「🗑️ 删除」进入删除模式，每条会话右边会出现垃圾桶，点哪条删哪条，会**就地展开一次确认**；再点「✖️ 退出删除」回来。删的如果不是当前会话，你正在聊的那条不受影响

## 资料库

- **支持格式**：PDF、Word（`.docx` / `.doc`）、PPT（`.pptx` / `.ppt`），单文件 200MB 以内
- **在线查看**：统一转成 PDF 后内嵌浏览器自带的阅读器。转 PDF 走本机 Office 的 COM 自动化，首次转换要十几秒（DLL 冷启动），之后复用同一个 Office 实例
- **没装 Office 时**：自动跳过转换，只把正文抽出来入库，列表里会说明「在线查看不可用」以及原因。原件仍可下载
- **正文抽取**：PDF 和可读的 Office 预览按实际页提取。没有可读预览时，`.docx` 和 `.pptx` 降级为文本索引，PPT 备注也可作为无页码片段检索
- **同名视为更新**：先准备新版本，入库成功后再替换。处理失败时保留原资料。旧引用仍可查看当时的片段，并标明原件版本是否可用
- **删除**：连原件、预览 PDF 和知识库切片一起清掉
- **「仅知识库」条目**：早期版本留下的、只有切片没有原件的来源也会列出来，可以删，但不能在线查看

## 知识库与检索

### 怎么工作的

新资料按页切片，每片保存资料版本和可确认的原页号。没有可靠页码的资料仍可按文本检索。检索用**向量召回与关键词召回**混合排序：

- **向量召回**：词袋哈希嵌入（离线），或装了 `sentence-transformers` 后用 `all-MiniLM-L6-v2`
- **关键词召回**：中文切相邻二元组（`计算/算机/机硬/硬件…`），英文按词切，`2.6.8` 这类题号作为完整词项，按查询词项的覆盖率排序

两路独立过滤低分片段，再由 DeepTutor 的 BM25 与倒数排名融合检索器排序。向量查询失败时，关键词仍可单独返回结果。`/search` 的 `confidence` 是两路用于入选判断的最高原始得分。Windows 上建议用 Python 3.13，Python 3.14 缺少上游 BM25 适配器时使用现有检索候选顺序。

上游模块的固定版本、许可证和改动记录见 [DeepTutor 来源说明](vendor/deeptutor/UPSTREAM.md)。检索继续读现有 ChromaDB，课程和练习继续读现有本地 JSON。升级时安装新增依赖即可，旧索引和历史记录可继续使用。

### 两处用到它

| 用处 | 触发方式 | 命中时显示 |
|---|---|---|
| 对话 | 每轮提问前在所选范围检索（可在设置里关） | 回复实际标出的出处 |
| 测验 | 点「📝 出题」时在所选范围检索 | 出题时提供的资料片段 |

旧知识库可以直接使用。旧切片没有可靠的原页定位时，出处只展示来源和片段。要给旧课件补齐原页链接，可以从资料库下载原件，再使用相同文件名上传。请先留存原件，也可先备份 `chroma_db/` 和资料目录。

如果现有索引的嵌入模型加载失败，系统仍可用关键词查询已入库的正文。补齐模型或恢复匹配的配置后再重新上传资料。

## 重建知识库索引

知识库里的向量是按**当时的规则**算好存进 `chroma_db/` 的。

> ⚠️ **只要动过 `rag_builder.py` 里的分词规则、哈希方式或向量维度，就必须重算一遍。**

不重算的话，库里存的老向量和现在查询时现算的向量不在同一个空间里，检索会退化成随机命中。表现是：

- 出题时「出题依据」老是那几页，或者干脆提示「没检索到相关内容」
- 对话里明明资料里有答案，却说「资料里没有相关内容」

```bash
# 先关掉 server.py 和 app.py —— Chroma 是本地文件库，两边同时写会打架
python rebuild_index.py --dry-run   # 只打印现状：多少切片、多少维，不改数据
python rebuild_index.py             # 自动备份 chroma_db/ 后原地重建
```

切片原文本来就存在 Chroma 里，重建只是取出来重新嵌入，**不会丢内容**。脚本先把新向量写在临时集合里、用一句中文试查确认真能命中，最后才替换旧集合；中途失败原始数据不动，`chroma_db.bak-<时间戳>/` 还留着备份。

## 常见问题

**前端打开是空白 / 一直转圈**
后端还没起来。看 `Tutor Server` 那个窗口，ChromaDB 首次加载要十几秒；确认 http://127.0.0.1:8000/docs 能打开。

**资料导入后点「👁️ 查看」是空白**
- 提示「在线查看不可用」→ 没装 Office 或转换失败，看列表里的原因说明
- 能打开但一片空白 → 换个浏览器，或在提示的链接里新标签页打开试试

**出题 / 对话老是说「没检索到相关内容」，但资料明明有**
按上面的「重建知识库索引」跑一次。如果只是想提高命中率，可以调低 `RAG_CONF_THRESHOLD`。

**中文检索感觉不太准**
新建知识库时可安装 `sentence-transformers` 并设 `TUTOR_OFFLINE=0` 尝试句向量。已有哈希索引不会因切换环境变量自动改用其他模型。更换模型需要在备份后重建向量。

**Office 转换卡住 / 超时**
单次转换超过 180 秒会放弃转换、只保留正文入库。PPT 页数特别多时很正常，可以先把原文件另存为 PDF 再上传。

**改了 `chat_db.json` 之后记录又变回去了**
`chat_db.json` 和 `learning_db.json` 在启动时读取。`study_db.json` 保存课程、题目和复习安排。备份或恢复学习进度时，请停掉后端并一起保留 `study_db.json` 和 `learning_db.json`。

**端口被占用**
后端固定 8000、前端默认 8501。用 `netstat -ano | findstr :8000` 找到占用进程再处理。

## 已知限制

- **只在 Windows 上验证过**。Linux / macOS 上 Office 转 PDF 和沙箱部分需要另想办法
- **单文件 200MB 上限**（Streamlit 默认），超大课件建议先拆分
- **扫描版 PDF 抽不出文字**：pymupdf 只读文字层，纯图片的 PDF 需要先 OCR
- **内置嵌入是词袋模型**，同义改写（「电脑」vs「计算机」）匹配不上，靠关键词召回兜底
- **会话没有并发保护**：`chat_db.json` 是整份读写，同时开多个浏览器窗口写同一个会话可能互相覆盖
